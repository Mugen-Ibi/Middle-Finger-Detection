# ジェスチャー評価データ

このリポジトリは学習済み MediaPipe Hand Landmarker と幾何ルールを使います。このデータは**判定・回帰評価用**で、MediaPipe の再学習に使ったデータではありません。

## 内容

| データ | 数 | 用途 |
| --- | ---: | --- |
| 公開実画像 | 5枚 | thumb_up、fist、victory、pointing_up、right_hands |
| 実画像の拡張条件 | 120 | 実モデルで左右反転・回転・明るさを検証 |
| 実画像由来のランドマーク | 120条件 | `public-landmarks.jsonl`、モデル再実行なしの回帰テスト |
| 合成ランドマーク | 10,240件 | 20ポーズ × 256変種 × 2シード |
| 関節別の追加合成ランドマーク | 5,632件 | 22ポーズ × 128変種 × 2シード、左右反転を各半数 |

`manifest.json` に公開元、元画像の SHA-256、モデルのバージョン、生成条件を記録しています。公開画像とその派生座標は MediaPipe の Apache-2.0 に従います。合成生成器は本リポジトリの MIT License に従います。個人のカメラ画像は収集せず、これらのファイルは exe に含めません。

## 再現

```powershell
npm.cmd run evaluate:gestures
npm.cmd test
npm.cmd run test:e2e
```

最初のコマンドは `test-results/gestures/` に development/evaluation の JSONL とクラス別混同行列 `metrics.json` を出力します。合成データは中指・いいね・Bad・その他の4分類で、16種類の指の伸展パターン、親指の上下・横向き・収納を含みます。左右、サイズ、位置、奥行き方向の回転、画面内回転、関節ノイズ、指の長さ、4種類の縦横比を変化させます。シードは固定され、外部取得なしで再生成できます。

ブラウザーテストは同梱済みの WASM モデルに実画像を渡し、`test-results/gestures/real-images.json` に座標と判定を記録します。512×512のキャンバスに最大辺380pxで描画し、通常は −20/0/20度 × 左右2通り × 明るさ0.7/1/1.3の18条件。thumb_up には90/160/180/200/270度も加え48条件、残り4画像は各18条件です。90/270度は横向きとして非対象、160/180/200度はBadとして評価します。VIDEOモードの決定的な順序で実行するため、追跡状態も結果に含まれます。

`robustness.mjs` はPIP・DIPの屈曲を個別に変え、少し曲げた中指、指先側で折りたたんだ隣接指、曖昧な人差し指、曲がった中指の陰性例を含めます。3軸の剛体回転、平行移動、拡大縮小、ノイズ、4縦横比を加え、左右反転あり・なしを等数生成します。developmentのシードは20261029、evaluationは7391337です。`metrics.json` の `robustness_*` にポーズ別・左右反転別の一致数を出力します。これは画像モデルの手の検出率を測るものではありません。

2026-10-29の全体レビューで、既存生成器のyaw変換もz成分を含めた剛体回転へ修正し、出力元を `procedural-v2` としました。追加生成器は各ポーズ・各縦横比で反転あり／なしの両方を生成し、その組み合わせを単体テストで確認します。CIではdevelopmentを含む全4シードも実行します。

## 追加評価（2026-10-29）

- 既存の合成2分割：各5,120/5,120。既存公開画像由来の保存座標：120/120。
- 追加の合成2分割：各2,816/2,816。各分割の左右反転あり・なしは、それぞれ1,408/1,408。
- 追加evaluationで旧ルールと比較：少し曲げた中指は62/128→128/128、DIPだけを折った隣接指は0/128→128/128、混在する屈曲は0/128→128/128。既存の陰性ポーズは維持。このセットはルール調整に使用しており、独立した実機精度ではありません。
- 公開画像を実WASMモデルに再入力した120条件も維持。両手同時・片手から両手への変更・追跡の揺れ・推論中断からの復帰・解除後の再発動は、時間系列の単体テストと人工カメラのブラウザーテストで確認。

## 結果と限界（2026-10-23）

- 合成：開発用5,120/5,120、評価用5,120/5,120が期待ラベルと一致。
- 公開画像：120/120条件が期待判定と一致。陽性は対象クラスが1手以上で検出されること、陰性は対象3クラスに反応しないことを確認。
- 親指方向の初期ルールは拡張108条件中94条件に一致。斜めの親指を落としていたため、方向の許容範囲を修正。この実画像セットは調整に使用しており、独立テスト精度ではありません。

**これらを実世界の精度100%と解釈しないでください。** 実画像の人数・背景は少なく、Badは同じ親指画像の回転、中指陽性は合成のみです。合成の2分割も同じ生成テンプレートを共有します。画像の拡張は新しい被験者を増やしません。学習済みモデルの重みは変更していません。

今後実写を増やす場合は、撮影同意・再配布権を確認し、被験者と撮影セッション単位で開発用／未使用評価用を分け、分割後に拡張してください。いいね・Bad・中指に加え、握り拳、ピース、開いた手、人差し指、横向きの親指、手なし、遮蔽、暗所、動作途中を含め、クラス別 precision/recall、手の検出失敗、動画での誤発火回数を別々に測定します。実データを追加していない段階で再学習済み・実機精度改善済みとは記載しません。
