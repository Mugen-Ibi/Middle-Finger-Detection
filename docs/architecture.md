# アーキテクチャ

## 処理の分担

```text
ランチャー (app.py / exe)
  └─ 127.0.0.1 の HTTP サーバー
       ├─ UI・JavaScript・WASM・モデルを配信
       └─ セッション・稼働確認・終了 API

ブラウザー
  ├─ CameraController → getUserMedia → 選択したカメラ
  │                                      └─ <video> に直接表示
  ├─ 映像の更新・明るさを確認
  └─ ImageBitmap を Web Worker へ転送
       └─ MediaPipe → 手のランドマーク
            └─ 姿勢判定 + GestureGate → 骨格表示・紙吹雪
```

カメラ映像は HTTP サーバーに送信しません。ランチャーは画面と静的アセットを提供するだけで、カメラ制御・認識・描画はブラウザー内で動きます。

## ファイル構成

| ファイル | 責務 |
| --- | --- |
| `app.py` | ループバック専用サーバー、ブラウザー起動、終了管理 |
| `web/index.html`, `web/style.css` | 画面とレスポンシブ表示 |
| `web/app.js` | UI 状態、動画フレーム、Worker、描画、診断情報 |
| `web/camera.js` | カメラ取得・切断・キャンセル・エラーの説明 |
| `web/inference-worker.js` | 同梱の MediaPipe を読み込み、CPU / WASM で推論 |
| `web/gesture.js` | 3D 関節の姿勢判定と時間方向の判定 |
| `scripts/prepare-assets.mjs` | 依存アセットのコピーとモデル検証 |
| `tests/` | 単体テスト・ブラウザーテスト・公開テスト画像 |

## カメラと状態管理

解像度や FPS、OS 固有のキャプチャバックエンドを強制せず、ブラウザーにモードの調整を任せます。機器を選択した場合は `deviceId.exact` で指定し、失敗時に別の機器へ自動で切り替えません。

カメラの開始要求には世代番号を付けます。停止・切り替え後に古い許可要求が完了しても、そのストリームを解放し、現在の映像を置き換えません。許可待ち中も停止できます。

取得のタイムアウトは15秒、動画再生の開始待ちは10秒です。表示中のページでフレーム更新が10秒以上止まった場合も、カメラを解放して案内を表示します。黒映像の警告は、フレームを受信できているかどうかと独立して判定します。暗い部屋でも警告が出るため、カメラ故障の断定には使用しません。

## 認識とジェスチャー

認識は Web Worker で行い、カメラ表示・停止操作をメインスレッドに残します。推論中の画像は1枚に制限し、次々とキューへ積みません。入力は最大幅640ピクセルへ縮小します。古いカメラセッションに属する結果は表示に反映しません。

MediaPipe は最大2手と各21点のランドマークを返します。判定には画像の縦横比に依存しない world 座標を使用します。中指の関節角度と伸びを確認し、人差し指・薬指・小指が曲がっている場合に候補とします。親指は判定対象外です。

`GestureGate` は約300ミリ秒かつ3サンプル以上の候補の継続で反応します。反応後は約450ミリ秒の解除を確認するまで再反応しません。長いサンプル欠落を、姿勢の連続保持として扱いません。

モデルの準備・推論に失敗してもカメラプレビューは維持し、モデルの再読み込み操作を提供します。

## サーバーと終了処理

- `127.0.0.1` のみにバインドします。通常ポートは8765で、使用中なら空きポートを使います。
- 配信対象は `web/` 内のファイルだけです。ディレクトリ一覧は配信しません。
- Host を検証し、POST には同一 Origin と実行ごとのセッショントークンを要求します。
- CSP で実行時の外部リクエストを制限します。
- ブラウザーは15秒ごとに稼働確認を送ります。確認が約300秒途切れると終了します。
- 「アプリを終了」はカメラと Worker を停止し、サーバーにも終了を要求します。

これらはローカル専用アプリの境界であり、公開 Web サーバーとしての利用を想定した構成ではありません。
