# アーキテクチャ

## 処理の分担

```text
ランチャー (app.py / exe)
  └─ 127.0.0.1 の HTTP サーバー
       ├─ UI・JavaScript・WASM・モデルを配信
       └─ セッション・稼働確認・終了 API

ブラウザー
  ├─ CameraController → getUserMedia → 選択したカメラ
  │                                      └─ <video> に直接表示
  ├─ 映像の更新・明るさを確認
  └─ ImageBitmap を Web Worker へ転送
       └─ MediaPipe → 手のランドマーク
            └─ 姿勢判定 + GestureGate → 骨格表示・メッセージ・エフェクト
```

カメラ映像は HTTP サーバーに送信しません。ランチャーは画面と静的アセットを提供するだけで、カメラ制御・認識・描画はブラウザー内で動きます。

## ファイル構成

| ファイル | 責務 |
| --- | --- |
| `app.py` | ループバック専用サーバー、ブラウザー起動、終了管理 |

| `web/app.js` | UI 状態、動画フレーム、Worker、描画、診断情報 |
| `web/camera.js` | カメラ取得・切断・キャンセル・エラーの説明 |
| `web/capture.js` | OBS用表示の切り替え、出力の縦横比、通常表示への復帰 |
| `web/inference-worker.js` | 同梱の MediaPipe を読み込み、CPU / WASM で推論 |
| `web/gesture.js` | 3D 関節の姿勢判定と時間方向の判定 |
| `web/celebration.js` | メッセージ選択、4種類の演出、アニメーションの開始・解除 |

## カメラと状態管理

解像度や FPS、OS 固有のキャプチャバックエンドを強制せず、ブラウザーにモードの調整を任せます。機器を選択した場合は `deviceId.exact` で指定し、失敗時に別の機器へ自動で切り替えません。

カメラの開始要求には世代番号を付けます。停止・切り替え後に古い許可要求が完了しても、そのストリームを解放し、現在の映像を置き換えません。許可待ち中も停止できます。

取得のタイムアウトは15秒、動画再生の開始待ちは10秒です。表示中のページでフレーム更新が10秒以上止まった場合も、カメラを解放して案内を表示します。黒映像の警告は、フレームを受信できているかどうかと独立して判定します。暗い部屋でも警告が出るため、カメラ故障の断定には使用しません。

## 認識とジェスチャー

認識は Web Worker で行い、カメラ表示・停止操作をメインスレッドに残します。推論中の画像は1枚に制限し、次々とキューへ積みません。入力は最大幅640ピクセルへ縮小します。古いカメラセッションに属する結果は表示に反映しません。

MediaPipe は最大2手と各21点のランドマークを返します。判定には画像の縦横比に依存しない world 座標を使用します。中指の関節角度と伸びを確認し、人差し指・薬指・小指が曲がっている場合に候補とします。親指は判定対象外です。

`GestureGate` は約300ミリ秒かつ3サンプル以上の候補の継続で反応します。反応後は約450ミリ秒の解除を確認するまで再反応しません。長いサンプル欠落を、姿勢の連続保持として扱いません。

モデルの準備・推論に失敗してもカメラプレビューは維持し、モデルの再読み込み操作を提供します。

## メッセージと演出

文章はおまかせ・定型文・自由入力から選び、演出は独立して選択します。おまかせは全候補を一巡するごとに並べ替え、巡回の境界でも同じ候補が連続しないようにします。自由入力は `textContent` で表示し、保存・送信しません。

演出プレビューは認識・カウント更新を経由せず、検知時と同じ描画処理だけを呼び出します。新しい演出は前の演出を解除して開始します。動きは経過時間を基準に描画し、約3秒で終了します。カメラ停止・検出の一時停止・タブ非表示でも描画とタイマーを解除します。`prefers-reduced-motion` が有効な場合は静止したメッセージだけを表示します。

背景の表示期間はメッセージ・エフェクトから独立しています。ポーズの確定で表示し、`GestureGate` が解除を確認すると隠します。認識結果が1.2秒以上途切れた場合も表示を解除します。背景は映像の上に別レイヤーとして表示するため、認識に渡す画像は引き続き元のカメラ映像です。

背景ファイルは Object URL からブラウザー内で読み込みます。画像は最大辺4096ピクセルの静止キャンバスに変換後、URL を解放します。動画は無音ループで表示し、非表示時に一時停止します。差し替え・解除・終了時に URL を解放し、読み込み途中の差し替えは世代番号とキャンセルで古い結果を破棄します。読み込み失敗時は前の背景を保持します。CSP はローカル画像・動画用の `blob:` のみ追加で許可します。

マスクは各手の world 座標による姿勢判定と対応する画像座標の組を使用します。中指の9〜12番の関節をプレビュー座標へ変換し、`object-fit: contain` の余白と左右反転を反映します。指の向きに合わせた枠内に、不透明な下地とスタンプまたはメディアを描画します。動画は背景とは別のファイル参照・再生状態を持ち、読み込みと解放には `MediaBackground` を再利用します。

マスクの表示は祝福カウントや約3秒の演出タイマーから独立しています。検出結果が来るたびに手ごとの座標を更新し、描画ループで動画を更新します。該当する手がない場合は即座に消し、結果が450ミリ秒以上途切れた場合も古い座標を破棄します。認識に渡すカメラ映像自体は変更しません。

## OBS ウィンドウキャプチャ

同じページ内で表示だけを切り替え、既存の映像・描画レイヤーを縦横比固定の領域に配置します。追加のカメラ取得や映像転送は行いません。通常表示への復帰時にはフォーカスとスクロール位置を戻します。

OBS用表示では設定・診断・警告・停止中の案内を隠し、エラー時にも自動で設定画面へ戻しません。非表示タブでの推論・演出停止は通常表示と共通です。

## サーバーと終了処理

- `127.0.0.1` のみにバインドします。通常ポートは8765で、使用中なら空きポートを使います。
- 配信対象は `web/` 内のファイルだけです。ディレクトリ一覧は配信しません。
- Host を検証し、POST には同一 Origin と実行ごとのセッショントークンを要求します。
- CSP で実行時の外部リクエストを制限します。
- ブラウザーは15秒ごとに稼働確認を送ります。確認が約300秒途切れると終了します。
- 「アプリを終了」はカメラと Worker を停止し、サーバーにも終了を要求します。

これらはローカル専用アプリの境界であり、公開 Web サーバーとしての利用を想定した構成ではありません。
