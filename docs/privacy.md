# プライバシーと公開時の注意

## アプリが処理するもの

カメラアクセスは利用者が **カメラを開始** を押した後に要求します。ブラウザーのカメラ許可はブラウザー自身が管理します。マイクアクセスは要求しません。

映像はブラウザー内のプレビューと手の認識に使用します。画像は Web Worker にメモリ内で渡し、認識結果を画面に返します。アプリは映像・ランドマークのファイル保存、録画、外部サーバーへのアップロードを行いません。

認識モデル・WASM・UI はローカルサーバーから読み込みます。通常の実行時通信はループバックへの静的ファイル取得と、セッション・稼働確認・終了のリクエストだけです。アカウント登録・API キー・利用状況分析サービスは使用しません。

初回の開発セットアップでは npm レジストリとモデル配布元へ接続します。テスト用 Chromium のインストールにも配布元への通信が発生します。これらの取得処理は、カメラ映像を送信する処理ではありません。ブラウザー・OS 自身の更新や同期はこのアプリの制御外です。

## ローカルのデータ

- カメラ名、機器選択、検出状態、カウントはページのメモリ内で扱います。
- 演出設定と自由入力のメッセージはページ内のみで使用します。アプリは保存・送信せず、診断情報にも含めません。ページの再読み込みでリセットします。
- ブラウザーはサイトごとのカメラ許可などを自身の設定に保持する場合があります。
- exe は実行時に同梱ファイルを OS の一時領域へ展開します。
- **診断情報をコピー** は利用者の操作でクリップボードに文字列を書き込みます。画像は含みませんが、カメラ名とエラー文は含まれます。

ブラウザーの拡張機能、画面録画ソフト、OS の診断機能などが別途データを取得する可能性までは、このアプリで制御できません。

## 公開リポジトリに含めないもの

- 実カメラの録画、人物・室内を含む画像、個人のスクリーンショット
- カメラの個別名称、端末名、機器 ID、シリアル番号、MAC アドレス
- ユーザー名、メールアドレス、個人フォルダーの絶対パス
- 認証トークン、Cookie、秘密鍵、API キー、`.env` の値
- ローカル診断ログ、ブラウザープロファイル、仮想環境、ビルド中間ファイル

`.gitignore` は生成物・ローカル設定を除外しますが、すでに追跡されているファイルや手動で強制追加したファイルには効きません。公開前に `git diff --cached` と `git diff --cached --name-only` を確認してください。

テストの入力は合成データまたは出典を記載した公開サンプルに限定します。`tests/fixtures/` の画像は第三者の公開テスト素材であり、利用者のカメラから収集した画像ではありません。

## 公開 Issue とコミット

診断情報をそのまま貼り付けず、機器の個別名称やパスを「内蔵カメラ」「プロジェクトフォルダー」などへ置き換えてください。症状の説明に実映像は不要です。

コミットの作成者名とメールアドレスも公開されます。公開用の表示名と GitHub の noreply アドレスなど、公開してよい識別情報を使用してください。リポジトリのファイルだけでなく、新しく作成するコミットのメタデータも確認対象です。

秘密情報を誤って含めた場合は、追加の公開を止め、関係する認証情報を失効・更新してから対処してください。ファイルを後から削除するだけでは過去のコミットから消えません。
