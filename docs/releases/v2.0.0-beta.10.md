# Gesture Party v2.0.0-beta.10

右手・左手の認識改善、両手専用「ダブルインパクト」、いいね！・Bad対応を含むWindows向けベータ版です。全ての自作コード、テスト、CI・ビルド・配布設定をレビューし、再現した問題を修正しました。

## 主な変更

- 関節角度と指全体の伸び率で、少し曲げた中指や指先側で折った隣接指に対応。左右反転や手の向きに依存しない3D判定を使用します。
- 両方の中指を同時に約0.3秒保持すると、シアンとピンクの専用エフェクトが発動します。片手からの追加、両手のマスク、カスタム文章、動きの抑制設定にも対応します。
- 親指を上に向ける「いいね！」と下に向ける「Bad」に対応。両手で異なる対象ポーズを出した場合は確定しません。
- 合成評価を15,872条件へ拡張し、正しい3D回転と各縦横比・左右反転の組み合わせを検証。公開画像由来の120条件も維持します。

## レビューで修正した問題

- WindowsのUNC・ドライブ・デバイスパスなどをファイルシステム解決より前に拒否し、検証したファイルを二重にURLデコードせず配信します。
- 終了前にセッション取得が完了していなくても、取得後に終了要求を送ります。遅着した応答やheartbeatの失敗が終了後の通信や表示を再開しません。
- 古い推論が続いた場合に骨格・検出表示・背景が残る問題を修正。有効な低速推論は保持に加算でき、手動マスクプレビューは独立して維持します。
- MAXモードのコンボ5以上で音の後半が欠落する問題を修正しました。
- PyInstallerを6.22.3へ更新し、[公式勧告 GHSA-9fxf-4qw3-ghmr](https://github.com/pyinstaller/pyinstaller/security/advisories/GHSA-9fxf-4qw3-ghmr) の修正済み版でビルドします。このアプリは管理者権限を要求しません。
- CIの全評価シード実行、ライセンス説明、評価件数の記載を整えました。

## 確認範囲と制限

単体・Python・ソース版とexe版のブラウザーテスト、合成評価、公開画像の実モデル評価をリリース条件としています。CIの成功を確認して公開します。

ブラウザーテストは人工カメラを使います。実カメラによる多人数・左右の手・照明差での認識精度、OBS本体での取り込みは未測定です。合成データや同じ公開画像からの拡張結果を、実世界の精度保証として扱わないでください。学習済みモデルの重みは変更していません。

## 使用方法

既存アプリを終了してから、Assetsの `MiddleFingerDetection.exe` を取得して起動してください。Windows 11 x64と更新済みのMicrosoft EdgeまたはGoogle Chromeに対応します。exeは未署名です。

`SHA256SUMS.txt` と `Get-FileHash .\MiddleFingerDetection.exe -Algorithm SHA256` を比較して整合性を確認できます。設定やファイル選択は再設定が必要です。カメラ映像・入力した文章・選択ファイルを外部へ送信しません。
