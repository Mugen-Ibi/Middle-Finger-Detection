# Gesture Party

Web カメラの映像から手を認識し、中指を立てるジェスチャーにメッセージやエフェクトで反応する Windows 向けローカルアプリです。好きな画像・動画をポーズ中の背景にしたり、指に追従するスタンプ・画像・動画のマスクを重ねたりできます。

カメラ映像と認識処理はブラウザー内で完結します。録画・画像保存・映像のアップロード・マイクの取得は行いません。モデルを同梱しているため、導入後はインターネット接続なしで使用できます。

## 必要な環境

| 用途 | 必要なもの |
| --- | --- |
| exe 版を使う | Windows 11 x64、Microsoft Edge または Google Chrome、カメラ |
| ソースから起動する | 上記に加え Python 3.11 または 3.12、Node.js 22、npm |
| 開発・自動テスト | 上記に加え Git、Playwright が用意する Chromium |
| exe をビルドする | Windows x64 と `requirements.txt` のビルド依存関係 |

ブラウザーは更新済みの版を使用してください。`getUserMedia`、`requestVideoFrameCallback`、Web Worker、WebAssembly、OffscreenCanvas が必要です。Linux / macOS と Windows ARM64 は配布・検証対象に含めていません。カメラの解像度やフレームレートは機器とブラウザーが決定します。

## 導入方法

### exe 版

1. [Releases](https://github.com/Mugen-Ibi/Middle-Finger-Detection/releases) を開き、使用するベータ版のリリースノートを確認します。
2. **Assets** から `MiddleFingerDetection.exe` をダウンロードします。`Source code` は実行ファイルではありません。
3. `MiddleFingerDetection.exe` を実行します。インストール、Python / Node.js の導入は不要です。
4. 自動で開いた Edge（見つからない場合は Chrome）の専用ウィンドウで、カメラを選んで **カメラを開始** を押します。Windows の既定ブラウザー設定は変更しません。
5. 初回はブラウザーのカメラアクセスを許可します。機器名がまだ表示されない場合は、許可後に **一覧を更新** して使う機器を選び直します。

内蔵カメラ・USB カメラ・スマートフォンの仮想カメラはそれぞれ別の機器です。使いたい機器を一覧から明示的に選んでください。スマートフォン連携の設定自体は、あらかじめ Windows とスマートフォン側で済ませてください。

exe は未署名です。ダウンロード元がこのリポジトリのビルドであることを確認してください。Firefox は対応対象外です。古い exe から Firefox が開く場合は、ページの URL を Edge / Chrome にコピーして開いてください。

ベータ版には未検証の機器や誤判定などの制限があります。同じリリースの `SHA256SUMS.txt` と、PowerShell の `Get-FileHash .\MiddleFingerDetection.exe -Algorithm SHA256` の結果を比較すると、取得したファイルの整合性を確認できます。開発中のビルドは **Actions → Build Windows exe → Artifacts** からも取得できます。

### 旧版から更新

旧版の画面で **アプリを終了** を押し、新リリースの exe をダウンロードして起動してください。設定、入力した文章、背景・マスクのファイル選択は引き継がれないため、新しい画面で設定し直します。画像や動画の元ファイルは変更しません。

### ソースから起動

リポジトリをクローン、または **Code → Download ZIP** で取得し、展開したプロジェクトのルートフォルダーで PowerShell を開きます。Python と Node.js を先にインストールしてください。

```powershell
py -3.11 -m venv .venv
npm.cmd ci
npm.cmd run prepare:assets
.\.venv\Scripts\python.exe app.py
```

Python 3.12 を使う場合は最初の行の `-3.11` を `-3.12` に変更します。Python Launcher の `py` がない環境では、インストール済み Python の `python -m venv .venv` を使ってください。仮想環境の有効化は不要です。

`prepare:assets` が認識モデルを取得し、チェックサムを検証します。初回の依存関係・モデルの取得にはネット接続が必要です。Python の起動処理には標準ライブラリしか使用しません。

`Launch-MiddleFingerDetection.cmd` からも起動できます。このスクリプトは `dist` 内の exe を優先します。ソースを編集した内容を確認するときは、上記の `python.exe app.py` を直接実行してください。

## 操作

| 操作 | 動作 |
| --- | --- |
| カメラを開始 | 選択したカメラから映像を取得 |
| 停止 | 映像取得を停止してカメラを解放 |
| 検出を一時停止 / 再開 | カメラ映像を表示したまま認識のみ切り替え |
| カメラの選択を変更 | 使用中のカメラを停止。開始ボタンで新しい機器を接続 |
| 左右反転 / 骨格表示 | 表示のみ変更 |
| アプリを終了 | カメラとローカルサーバーを終了 |

「検出の状態」の **認識頻度の上限** は、標準の30回/秒と、負荷を抑える15回/秒から選べます。これは認識処理の上限で、カメラ映像のFPSは変更しません。実際の認識速度はPCの性能によって下がる場合があり、画面には直近5秒の認識速度を表示します。

「映らないとき・診断情報」では、推論時間とフレーム受信から結果反映までの時間を中央値 / p95で確認できます。p95は95%のサンプルが収まる値です。450ミリ秒を超えた古い結果は表示に使わず、破棄件数を診断に表示します。設定や性能指標は保存・送信しません。

手全体をカメラに向け、中指だけを伸ばして約0.3秒キープします。親指の位置は問いません。一度ジェスチャーを戻すと再び反応します。画面のカウントはページを再読み込みするとリセットされます。

### メッセージとエフェクト

「祝福の演出」で、検知時の文章とエフェクトを個別に設定できます。

| メッセージモード | 動作 |
| --- | --- |
| おまかせ | 8種類のメッセージを一巡するごとに並べ替えて表示。同じメッセージは連続しません |
| 定型文を選択 | 好きな定型文を毎回表示 |
| 自由入力 | メインテキスト（60文字まで）とサブテキスト（100文字まで・省略可）を表示 |

自由入力のメインが空欄の場合は「GESTURE DETECTED!」を表示します。入力内容は通常の文字として扱い、HTML は実行しません。

エフェクトは **紙吹雪・スターシャワー・花火・ネオンリング** の4種類です。固定選択か、同じ演出が連続しない「おまかせ」を選べます。「演出を試す」はカメラなしで使用でき、祝福カウントを増やしません。演出は約3秒で終了します。

設定と入力内容はページ内のみで保持し、保存・送信しません。再読み込みで初期状態に戻ります。OS / ブラウザーでアニメーションの抑制を設定している場合は、動くエフェクトを省略してメッセージを表示します。

### ポーズ中の画像・動画背景

「祝福の演出」内の **ポーズを維持している間の背景 → 選んだ画像・動画** で、端末内のファイルを指定できます。PNG / JPEG / WebP などの画像と、ブラウザーで再生できる MP4 / WebM などの動画に対応します。拡張子が同じでも、動画のコーデックによって再生できない場合があります。

- 中指のポーズが確定すると背景を表示し、ポーズを維持している間は表示を続けます。メッセージ・エフェクトは約3秒で終了します。
- 手を戻した状態が約0.45秒続くと、カメラ映像に戻ります。背景表示中も実際のカメラ映像から認識を続けます。
- 動画は毎回先頭から無音でループ再生します。画像は静止画として表示し、アニメーション画像も1フレームのみ使用します。
- **画面いっぱい** は中央を基準に切り取り、**全体を表示** は余白を付けて縦横比を保ちます。
- **演出を試す** では背景も約3秒プレビューします。**背景ファイルを解除** で読み込み済みのファイルを解放できます。
- 停止・検出の一時停止・タブ非表示・認識の中断時には背景を隠し、動画も停止します。アニメーション抑制設定では動画を静止状態で表示します。

背景ファイルとファイル名は端末内でのみ扱い、サーバーへ送信せず、診断情報にも含めません。ファイルはコピー・保存せず、ページを再読み込みすると再選択が必要です。

### 中指のマスク

**中指のマスク → マスクの種類** で **スタンプ** または **選んだ画像・動画** を選びます。初期状態はオフです。

- スタンプは黒帯・モザイク柄・星・ハート・スマイル・禁止マークの6種類です。モザイク柄は装飾用の柄で、カメラ画像を加工する方式ではありません。
- 中指を検出している間、指の位置・向き・大きさに追従して重ねます。両手を検出した場合はそれぞれに表示し、左右反転にも対応します。
- メッセージや紙吹雪の終了後も表示を続けます。手を戻すと解除し、認識結果が途切れた場合も約0.45秒で古い位置のマスクを消します。
- 任意の画像・動画を指定できます。画像は静止画、動画は無音ループで使用します。透過部分には下地を付け、ファイルを指のマスク枠に合わせて中央で切り取ります。
- **マスクの大きさ** で範囲を80〜200%に調整できます。**演出を試す** では画面中央に約3秒表示し、カメラやカウントを使わず確認できます。
- 背景とマスクには別々のファイルを指定でき、同時に使用できます。ファイルは保存・送信せず、再読み込みで選択を解除します。

位置は認識結果に基づくため、速い動きや追跡の遅れによって指がマスクからはみ出す場合があります。必要に応じて大きさを調整してください。停止・検出の一時停止・タブ非表示・オフへの切り替えで描画と動画再生を止めます。

タブを閉じるとカメラを解放し、ローカルサーバーは通常約5分後に自動終了します。すぐに終了したい場合は **アプリを終了** を使ってください。デモ向けの簡易判定のため、照明、手の隠れ方、撮影角度によって誤判定することがあります。

### OBS のウィンドウキャプチャで使う

1. Edge / Chrome の専用ウィンドウでアプリを開き、カメラを開始します。カメラと認識モデルの状態、背景・マスク・演出を確認してください。骨格が不要な場合は **手の骨格を表示** をオフにします。
2. 設定下部の **OBS ウィンドウキャプチャ** で **16:9・4:3・1:1** を選び、**OBS用表示に切り替え** を押します。
3. OBS のソースに **ウィンドウキャプチャ** を追加し、このブラウザーウィンドウを選択します。カーソルのキャプチャはオフにしてください。
4. OBS 側でブラウザーのタブ・アドレスバーや外側の黒い余白をクロップし、シーン内の大きさを調整します。ブラウザーの F11 キーで全画面にすると、タブ・アドレスバーを隠せます。

OBS用表示はウィンドウ内に収まる最大サイズで選択した縦横比を保ちます。カメラ映像は引き伸ばさず全体を表示し、比率が違う部分には黒い余白を付けます。背景・マスク・メッセージ・エフェクト・骨格の表示設定はそのまま適用されます。ウィンドウやズームを変更した場合は、OBS 側のクロップ範囲も確認してください。

**Esc キー** または **映像部分のダブルクリック** で通常の設定画面に戻ります。切り替えてもカメラ・選択したファイル・設定・カウントは維持します。F11 の全画面表示は F11 で解除できます。再読み込みすると通常表示に戻り、設定は初期化されます。

OBS用表示では操作パネル、機器名、警告、カメラ停止中の案内を隠します。カメラ停止時は黒い画面になるため、映像が止まった場合は通常表示に戻して状態を確認してください。警告やエラーから自動で通常表示に戻ることはありません。

配信中はブラウザーを最小化せず、アプリのタブを選択したままにしてください。タブが非表示になると検出と演出が停止します。カメラは本アプリから取得するため、同じ機器を OBS の「映像キャプチャデバイス」でも開いて競合する場合は、OBS 側のカメラ取得を停止してください。これはブラウザーのウィンドウを取り込む方式で、OBS のブラウザソースへの直接入力には対応していません。

## テストとビルド

導入済みの環境で、次を実行します。

```powershell
npm.cmd test
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

Windows exe の生成:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name MiddleFingerDetection --add-data "web;web" app.py
```

生成先は `dist\MiddleFingerDetection.exe` です。モデル・WASM・UI・Python ランタイムを同梱します。ビルド手順と生成物の検証は [開発ガイド](docs/development.md) を参照してください。
